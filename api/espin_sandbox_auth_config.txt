Set these environment variables in the sandbox deployment. Do not commit this file with real addresses.

SANDBOX_AUTH_HASH_SECRET=<a long random secret>
SANDBOX_ALLOWED_ORIGIN=https://your-sandbox-domain.example
SANDBOX_FROM_EMAIL=ESPIN LINK Sandbox <info@espinmedical.com>
SANDBOX_EVALUATOR_ASSIGNMENTS={"manager@example.com":{"role":"manager"},"rep.a@example.com":{"role":"rep","assigned_rep_id":"REP_A"},"rep.b@example.com":{"role":"rep","assigned_rep_id":"REP_B"},"rep.c@example.com":{"role":"rep","assigned_rep_id":"REP_C"}}

Deploy espin_sandbox_send_pin.js as /api/send-pin.js and espin_sandbox_verify_pin.js as /api/verify-pin.js.

The approved-email mapping belongs in deployment environment configuration, not ESPIN LINK project data. The handlers use the email only while sending/verifying a PIN and store KV keys using an HMAC-derived identifier. They log neither email addresses nor PIN values.
